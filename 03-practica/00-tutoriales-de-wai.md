# Tutoriales de WAI para seguir practicando

Para varias técnicas el W3C ya tiene tutoriales completos, con ejemplos de código. En este repo no se copian: se enlazan, y los archivos de práctica agregan comentario, ejercicios y contexto uruguayo.

| Tema | Tutorial | Archivo del repo |
|---|---|---|
| Imágenes | https://www.w3.org/WAI/tutorials/images/ | `01-imagenes.md` |
| Árbol de decisión para textos alternativos | https://www.w3.org/WAI/tutorials/images/decision-tree/ | `01-imagenes.md` |
| Estructura de página | https://www.w3.org/WAI/tutorials/page-structure/ | `02-estructura-y-navegacion.md` |
| Menús | https://www.w3.org/WAI/tutorials/menus/ | `02-estructura-y-navegacion.md` |
| Tablas | https://www.w3.org/WAI/tutorials/tables/ | Sin archivo propio todavía |
| Formularios | https://www.w3.org/WAI/tutorials/forms/ | `04-formularios.md` |

Audio y video accesibles: https://www.w3.org/WAI/media/av/

Todos los tutoriales: https://www.w3.org/WAI/tutorials/

Consejos para empezar: https://www.w3.org/WAI/tips/

Para una primera revisión rápida de una página, el W3C tiene también una guía de revisiones sencillas ("Easy Checks"): https://www.w3.org/WAI/test-evaluate/preliminary/

Los tutoriales tienen traducciones; el listado está en https://www.w3.org/WAI/translations/
