# Material original (2016 a 2019)

Este repo es una versión actualizada de materiales que Silvia Da Rosa escribió entre 2016 y 2019 sobre WCAG 2.0. Ese material original no está copiado acá: se enlaza cuando es público y se resume en una nota dentro de cada archivo nuevo ("Nota sobre el original").

Los originales no se mantienen. Si algo difiere entre un original y el repo, vale el repo.
